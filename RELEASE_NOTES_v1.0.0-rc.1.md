## Overview
This release candidate introduces a unified local dashboard for Claude Code and Codex usage analytics, with expanded session history and search capabilities.

## Highlights
- Unified usage reporting across Claude and Codex
- Session history support for both sources
- Cross-session search with merged results
- Session deletion APIs for Claude and Codex sessions
- Improved security and stability in server endpoints

## Quality
- Test suite status: 37 passed, 0 failed

## Known Limitations
- Intended for local use (not a production deployment package)
- Codex session cost in local JSONL is limited in current data source
